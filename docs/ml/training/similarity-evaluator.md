# Training: ML-002 Similarity Evaluator (v1.1.0)

- **Notebook:** `notebooks/02_train_similarity_evaluator.ipynb`, generated by `scripts/generate_kaggle_notebooks.py`.
- **Spec:** `docs/ml/models/similarity-evaluator.md`
- **Status:** authored 2026-11-26; not yet run.

## Data
- **Source:** O*NET 31.0 (CC BY 4.0), checksum-verified as for ML-001. **No real user data.**
- **Training pairs:** (anchor, positive) titles of the same occupation, from train-split occupations only. There are up to 20 titles and 50 pairs per occupation; 39,927 pairs were measured locally on 2026-11-26.
- **Graded evaluation pairs:** both titles come from held-out occupations.

  | Label | Pair |
  |---|---|
  | 3 | same occupation |
  | 2 | O*NET "Primary-Short" related occupation |
  | 1 | "Primary-Long" related occupation |
  | 0 | different SOC major group |

  These labels are a **proxy** for the human-labelled benchmark the spec mentions; no such benchmark is available. The test split has about 800 pairs.
- **Split:** by occupation, stratified by SOC major group (80/10/10).

## Training
- **Model:** `sentence-transformers/all-MiniLM-L6-v2`.
- **Loss:** `MultipleNegativesSymmetricRankingLoss` (spec §8), with a no-duplicates batch sampler.
- **Settings:** learning rate 2e-5, 10% warmup, 4 epochs, batch size 64, FP16 on GPU. The best checkpoint is chosen by validation Spearman.

## Export and evaluation
- **Export:** the fine-tuned transformer is exported to ONNX (opset 17) and dynamically quantised to INT8 (`model.onnx`, spec §10).
- **Metrics use the shipped INT8 model,** with mean pooling and normalisation identical to `SimilarityEvaluatorRunner`.

| Metric | Criterion (spec) |
|---|---|
| Precision of pairs scored >= 0.70 that are same-occupation or Primary-Short | >= 0.90 |
| AC-ML-002.1: "Software Developer" vs "Software Engineer" | >= 0.85 |
| AC-ML-002.2: "Software Developer" vs "Dental Assistant" | < 0.30 |
| Pearson r and Spearman rho (scores vs graded labels); INT8-vs-PyTorch cosine parity | reported only (Pearson un-gated by D-008) |

A failed criterion stops the export, as for ML-001.

## Transfer
Extract `similarity_evaluator_bundle.tar.gz` into `models/similarity-evaluator/v1.1.0/`, then run `findrr model inspect ML-002`.
